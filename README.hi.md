# alto

[monome norns](https://monome.org/docs/norns/) के लिए तीन परतों वाला पॉलीफ़ोनिक सिंथेसाइज़र, जिसे लगभग पूरी तरह स्क्रीन देखकर बजाया जा सकता है: हर पेज संख्याओं की सूची नहीं, बल्कि ध्वनि का एक चित्र है।

![alto के सभी आठ पेज](docs/sheet.png)

- हर नोट पर **3 आवाज़ें (voices)** एक साथ, हर आवाज़ का अपना इंजन (18 में से चुनें), वॉल्यूम, ऑक्टेव, ट्यूनिंग और LFO
- एनवेलप, कीट्रैकिंग और K3 "स्वीप" वाला **फ़िल्टर**
- **आर्पेजिएटर** (4 प्रकार, 4 गति, लेगाटो तक गेट) और **कॉर्ड मोड** (12 कॉर्ड)
- **3 रिंग वाला पॉलीरिद्मिक सीक्वेंसर**: हर आवाज़ के लिए एक रिंग, हर रिंग की अपनी लंबाई और दिशा, साथ में जनरेटिव धुनें
- **इफ़ेक्ट्स**: बिटक्रश, डिस्टॉर्शन, रिंग मॉड्यूलेटर, रिवर्ब और एक ग्रैन्युलर "स्पेस" जो सूखी ध्वनि से बादल और फिर शिमर तक जाता है
- **10 फ़ैक्टरी प्रीसेट + 10 यूज़र स्लॉट**
- किसी भी जुड़े डिवाइस से MIDI नोट इनपुट (पोर्ट 1–4)

## ज़रूरतें

- norns (कोई भी: shield, standard या fates)
- नोट बजाने के लिए MIDI कीबोर्ड; कीबोर्ड के बिना alto सीक्वेंसर के ज़रिए बजता है

## इंस्टॉल

maiden में:

```
;install https://github.com/buenosairesfront/alto
```

फिर नया इंजन `UmaFlagship` कंपाइल होने के लिए **norns को रीस्टार्ट करें** (SYSTEM > RESTART), और SELECT से **alto** लोड करें।

## कंट्रोल

हर पेज पर: **K2 + E1** पेज बदलता है, **K1** होल्ड (नोट लैच) चालू/बंद करता है। कोई भी बटन इंट्रो छोड़ देता है।

### 1 · बजाना

![बजाना](docs/1_play.png)

| कंट्रोल | काम |
|---|---|
| E1 | स्पेस: सूखी ध्वनि → ग्रैन्युलर बादल → शिमर |
| E2 | फ़िल्टर रेज़ोनेंस |
| E3 | फ़िल्टर कटऑफ़ |
| K2 | आर्पेजिएटर चालू/बंद |
| K2 + E2 / E3 | आर्पेजियो का प्रकार / गति |
| K2 + E1 (आर्प मेनू खुला हो) | आर्प गेट (अधिकतम = लेगाटो) |
| K3 | फ़िल्टर स्वीप (दबाए रखें = सस्टेन) |
| K3 को 0.5 सेकंड दबाए रखें | कॉर्ड मोड चालू/बंद |

### 2 · आवाज़ें

![आवाज़ें](docs/2_voices.png)

| कंट्रोल | काम |
|---|---|
| E1 | आवाज़ चुनें |
| E2 | वॉल्यूम |
| E3 | इंजन |
| K2 | आवाज़ चालू/बंद |
| K3 | LFO चालू/बंद |
| K3 + E1 / E2 / E3 | LFO की गति / आकार / मात्रा |

इंजन: sine, square, tri, fm, phys, perc, pad, pluck, gendy, formant,
pmosc, blip, lfcub, syncsaw, logistic, pink, blit, vosim

### 3 · ट्यूनिंग

![ट्यूनिंग](docs/3_tune.png)

| कंट्रोल | काम |
|---|---|
| E1 | आवाज़ चुनें |
| E2 / E3 | सेमीटोन / सेंट |
| K2 / K3 | सेमीटोन / सेंट को 0 करें |

### 4 · adsr

![adsr](docs/4_adsr.png)

| कंट्रोल | काम |
|---|---|
| E2 | बिंदु चुनें |
| E3 | उसे खिसकाएँ |
| K3 | एनवेलप फ़िल्टर को भी चलाता है |

### 5 · कॉर्ड

![कॉर्ड](docs/5_chord.png)

**E2** कॉर्ड मोड का कॉर्ड चुनता है: maj, min, sus2, sus4, dim, aug,
maj7, min7, dom7, add9, maj9, min9

### 6 · सीक्वेंसर

![सीक्वेंसर](docs/6_sequencer.png)

तीन अंडाकार रिंग: बाहर **A**, बीच में **B**, अंदर **C**। हर रिंग सिर्फ़ अपनी आवाज़ बजाती है और उसके स्टेप्स की संख्या अलग होती है, इसलिए सुइयाँ धीरे-धीरे अलग हो जाती हैं (पॉलीरिद्म)। हर स्टेप नोट की ऊँचाई के साथ बाहर की ओर बढ़ता है; आधार पर बिंदु का मतलब विराम है। घड़ी सोलहवें नोट में चलती है और norns की क्लॉक का पालन करती है।

| कंट्रोल | काम |
|---|---|
| K3 | चलाएँ / रोकें (सभी रिंग) |
| K3 + E1 | रिंग चुनें |
| K3 + E2 | दिशा: आगे, पीछे, आगे-पीछे, रैंडम |
| K3 + E3 | चुनी गई रिंग चालू/बंद |
| K2 | चुनी गई रिंग में रिकॉर्ड करें (रुकी हो तो शुरू हो जाती है) |
| E1 | स्टेप्स की संख्या |
| E2 | स्टेप चुनें |
| E3 | स्टेप की ऊँचाई (न्यूनतम = विराम) |
| K2 + E3 | चुने गए स्टेप की लंबाई |
| K2 + E2 | सभी स्टेप्स की लंबाई (अधिकतम = जुड़े हुए) |
| K1 + E3 | जनरेटिव धुनें (दाएँ = नई, बाएँ = पिछली) |
| K1 को 0.5 सेकंड दबाए रखें | चुना गया स्टेप मिटाएँ |

### 7 · इफ़ेक्ट्स

![इफ़ेक्ट्स](docs/7_fx.png)

| कंट्रोल | काम |
|---|---|
| E1 | इफ़ेक्ट चुनें: crush, dist, ring, verb |
| E2 / E3 | उसके दो पैरामीटर |
| K2 | इफ़ेक्ट चालू/बंद (मान बने रहते हैं) |

### 8 · प्रीसेट

![प्रीसेट](docs/8_presets.png)

| कंट्रोल | काम |
|---|---|
| E2 / E3 | स्लॉट चुनें |
| K2 | लोड / सेव (K2 से पुष्टि करें) |
| K3 | बाहर निकलें |

फ़ैक्टरी प्रीसेट: glass keys, analog brass, deep sub, acid line, stellar pad,
vox choir, klavinsky, chaos drone, metal bell, perc keys।
यूज़र प्रीसेट `~/dust/data/alto/user_presets.tab` में सेव होते हैं।
