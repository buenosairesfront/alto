# alto

[monome norns](https://monome.org/docs/norns/) 用の 3 レイヤー・ポリフォニック・シンセサイザー。
ほぼ画面を見るだけで演奏できるように作られていて、どのページも数値の一覧ではなく音の絵になっています。

![alto の全 8 ページ](docs/sheet.png)

- 1 つのノートに **3 つのボイス**を重ねる。各ボイスに独自のエンジン（18 種類から選択）、音量、オクターブ、チューニング、LFO
- エンベロープ、キートラッキング、K3 の「スイープ」付き**フィルター**
- **アルペジエーター**（4 タイプ、4 速度、レガートまでのゲート）と**コードモード**（12 種類のコード）
- **3 リングのポリリズム・シーケンサー**：ボイスごとに 1 つのリング。長さと方向はリングごとに独立。ジェネレーティブなメロディ機能付き
- **エフェクト**：ビットクラッシュ、ディストーション、リングモジュレーター、リバーブ、そしてドライ → 粒子の雲 → シマーへと変化するグラニュラーな「スペース」
- **ファクトリープリセット 10 個 + ユーザースロット 10 個**
- 接続した任意の機器からの MIDI ノート入力（ポート 1〜4）

## 必要なもの

- norns（shield、標準モデル、fates のいずれでも可）
- ノートを弾くための MIDI キーボード。キーボードがなくてもシーケンサーで音を出せます

## インストール

maiden から：

```
;install https://github.com/buenosairesfront/alto
```

その後、新しいエンジン `UmaFlagship` をコンパイルするために **norns を再起動**（SYSTEM > RESTART）し、SELECT から **alto** を読み込みます。

## 操作

全ページ共通：**K2 + E1** でページ切り替え、**K1** でホールド（ノートのラッチ）オン/オフ。
どのキーでもイントロをスキップできます。

### 1 · プレイ

![プレイ](docs/1_play.png)

| 操作 | 機能 |
|---|---|
| E1 | スペース：ドライ → 粒子の雲 → シマー |
| E2 | フィルターのレゾナンス |
| E3 | フィルターのカットオフ |
| K2 | アルペジエーター オン/オフ |
| K2 + E2 / E3 | アルペジオのタイプ / 速度 |
| K2 + E1（アルペジオメニュー表示中） | ゲートの長さ（最大 = レガート） |
| K3 | フィルタースイープ（押し続けるとサステイン） |
| K3 を 0.5 秒長押し | コードモード オン/オフ |

### 2 · ボイス

![ボイス](docs/2_voices.png)

| 操作 | 機能 |
|---|---|
| E1 | ボイス選択 |
| E2 | 音量 |
| E3 | エンジン |
| K2 | ボイス オン/オフ |
| K3 | LFO オン/オフ |
| K3 + E1 / E2 / E3 | LFO のテンポ / 波形 / 深さ |

エンジン：sine, square, tri, fm, phys, perc, pad, pluck, gendy, formant,
pmosc, blip, lfcub, syncsaw, logistic, pink, blit, vosim

### 3 · チューニング

![チューニング](docs/3_tune.png)

| 操作 | 機能 |
|---|---|
| E1 | ボイス選択 |
| E2 / E3 | 半音 / セント |
| K2 / K3 | 半音 / セントを 0 に戻す |

### 4 · adsr

![adsr](docs/4_adsr.png)

| 操作 | 機能 |
|---|---|
| E2 | ポイント選択 |
| E3 | ポイントを動かす |
| K3 | エンベロープでフィルターも動かす |

### 5 · コード

![コード](docs/5_chord.png)

**E2** でコードモードのコードを選択：maj, min, sus2, sus4, dim, aug,
maj7, min7, dom7, add9, maj9, min9

### 6 · シーケンサー

![シーケンサー](docs/6_sequencer.png)

楕円のリングが 3 つ：外側が **A**、中央が **B**、内側が **C**。各リングは自分のボイスだけを鳴らし、ステップ数もそれぞれ独立しているので、針が少しずつずれていきます（ポリリズム）。各ステップは音の高さに応じて外側へ伸び、底辺の点は休符です。クロックは 16 分音符で進み、norns のクロックに同期します。

| 操作 | 機能 |
|---|---|
| K3 | 再生 / 停止（全リング） |
| K3 + E1 | リング選択 |
| K3 + E2 | 方向：順方向、逆方向、往復、ランダム |
| K3 + E3 | 選択したリングのオン/オフ |
| K2 | 選択したリングに録音（停止中なら再生開始） |
| E1 | ステップ数 |
| E2 | ステップ選択 |
| E3 | ステップの音の高さ（最小 = 休符） |
| K2 + E3 | 選択したステップの長さ |
| K2 + E2 | 全ステップの長さ（最大 = タイ） |
| K1 + E3 | ジェネレーティブ・メロディ（右 = 新しく生成、左 = 前に戻る） |
| K1 を 0.5 秒長押し | 選択したステップを消去 |

### 7 · エフェクト

![エフェクト](docs/7_fx.png)

| 操作 | 機能 |
|---|---|
| E1 | エフェクト選択：crush, dist, ring, verb |
| E2 / E3 | 2 つのパラメーター |
| K2 | エフェクト オン/オフ（値は保持） |

### 8 · プリセット

![プリセット](docs/8_presets.png)

| 操作 | 機能 |
|---|---|
| E2 / E3 | スロット選択 |
| K2 | 読み込み / 保存（K2 で確定） |
| K3 | 閉じる |

ファクトリー：glass keys, analog brass, deep sub, acid line, stellar pad,
vox choir, klavinsky, chaos drone, metal bell, perc keys。
ユーザープリセットは `~/dust/data/alto/user_presets.tab` に保存されます。
